A modern, high-performance, single-page luxury jewellery web application showcasing the exclusive **Arwa 53 Collection** of gold bangles, bracelets, and bespoke jewellery pieces. Complete with physical boutique location details, interactive concierge actions, live wishlist drawer, and direct WhatsApp / phone contact integration.

## 🚀 Quick Start (Run Locally)

### Option 1: Python HTTP Server (Zero Dependencies)
```bash
# Clone the repository
git clone https://github.com/mufaddalkt/arwa53store.git
cd arwa53store

# Run local web server
python -m http.server 5173
```
Then open [http://localhost:5173](http://localhost:5173) in your browser.

---

### Option 2: Node.js / NPM
```bash
# Install dependencies
npm install

# Start local dev server
npm start
```
